# snyk-secure-development skill

This repository skill applies Coding Standards §6 to Devin-assisted source and
dependency changes. It requires Snyk tool discovery/authentication, Snyk Code,
Snyk Open Source where applicable, ecosystem-native audits, remediation, and
honest reporting of blocked scans.

`SKILL.md` is the executable skill definition. Snyk remains additive to Cargo
Audit, Pip Audit, Gitleaks/native GitHub secret controls, and the existing
quality gates.
