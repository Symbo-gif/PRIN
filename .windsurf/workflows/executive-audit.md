Authoritative definition: `DOCS/standards/Executive_Audit_Governance_and_Methodology.md`.
`NNN` is the executive audit sequence number (001, 002, …) — use the next
unused number in `DOCS/audits/`.

1. Establish governance and methodology if not present (`DOCS/standards/Executive_Audit_Governance_and_Methodology.md`, `DOCS/audits/TEMPLATE_Executive_Audit_Report.md`).
2. Perform full multi-domain audit across E1–E10.
3. Compile Executive Audit Report (`DOCS/audits/EXECUTIVE_AUDIT_REPORT_NNN.md`).
4. Formulate Remediation Plan (immediate vs pass-forward placeholders).
5. Execute remediation, bring docs to standards, add retroactive session/changelog updates tagged `[RETROACTIVE UPDATE - Executive Audit NNN]`.
6. Run full verification suite (tests, linters, security scans, docs build, snyk).
7. Document, commit, and push changes to origin.
