# .windsurf/rules/ — Windsurf project rules

This directory contains Windsurf-compatible PRIN governance and workflow rules.
`prin-secure-development.md` is the always-on repository authority and security
protocol; the Vibe Flow guide supplies optional role/workflow routing.

The project plan and normative standards win if an operational rule diverges.
Retired VibeCheck state is historical and non-authoritative.
