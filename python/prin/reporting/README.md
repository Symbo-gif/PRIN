# prin.reporting (Reporting & Visualization)

Benchmark JSON reports, publication figures, LaTeX tables, and profiling (Phases 1 & 6).

## Overview

Ports of PRINet 3.0 reporting tools:
- Benchmark JSON report generation adhering to established schema.
- Publication-quality 300 DPI matplotlib figure generation.
- LaTeX table generation.
- Integrated profiling wrapping `torch.profiler` and Rust `tracing` spans.
