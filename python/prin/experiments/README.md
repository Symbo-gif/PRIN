# prin.experiments (Experimentation frameworks)

Ablation, statistical, adversarial, and fair training frameworks (Phase 5).

## Overview

Reorganization of PRINet 3.0 experiment tools:
- `experiments.ablation`: Systematic model and dynamics ablation framework.
- `experiments.stats`: Multi-seed bootstrap confidence intervals, Welch t-tests.
- `experiments.adversarial`: FGSM and PGD adversarial robustness evaluations.
- Fair training framework: Identical loss, optimizer, data augmentation, and parameter budgets.
