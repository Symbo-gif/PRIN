## Caveat

The 90 missed lines in `cubecl.rs` are the two `#[cube(launch)]` kernel
functions:

- `mean_field_rk4_stage`
- `mean_field_rk4_finalize`

These functions are not executed as host CPU code; CubeCL compiles them to the
selected compute runtime (wgpu/WGSL or the CubeCL CPU interpreter) and they run
inside that runtime. `cargo-llvm-cov` therefore cannot instrument them. Their
correctness is validated by the host-level kernel-equivalence tests
(`wgpu_matches_cpu_reference_for_small_n`, `wgpu_matches_cpu_reference_at_one_million`,
`cpu_matches_cpu_reference_for_small_n`) against the CPU reference
implementation, which is 100% instrumented and covered.
