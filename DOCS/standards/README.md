# DOCS/standards/ — normative engineering standards

All contributions are governed by these documents:

- `Development_Workflow_and_Audit_Standards.md` — Session Cycle and deviations.
- `Coding_Standards.md` — Rust/Python design, quality, and security controls.
- `Testing_Standards.md` — test layers, tolerances, and coverage.
- `Documentation_Standards.md` — API/project documentation and S4 closure.
- `Benchmarking_and_Reproducibility_Standards.md` — performance evidence.
- `Experimentation_Standards.md` — pre-registration and scientific integrity.
- `Versioning_and_Release_Standards.md` — versions, CI, packaging, and releases.

Amendments require evidence, maintainer approval, and an entry in the Project
Plan amendment log. Operational tool instructions cannot override these files.
