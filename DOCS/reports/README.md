# DOCS/reports/ — Project State Reports

One report per closed Session Cycle (written in S4), named
`NNN-project-state.md`. The latest report is the **single authoritative
statement of where the project is on the planned trajectory** — every session
starts by reading it (Development Workflow Standards §6).

- Template: [`TEMPLATE_Project_State_Report.md`](TEMPLATE_Project_State_Report.md)
- Contains the cumulative **deviation ledger** and the **next WP declaration**.
- Reports are append-only history; corrections go in the next report.
