# .claude/ — Claude compatibility configuration

This directory contains repository-scoped Claude orchestration instructions and
specialized agent descriptions. It mirrors PRIN governance for compatible tools;
`DOCS/PRIN_Project_Plan.md`, `DOCS/standards/`, the latest Project State Report,
and the active session brief remain authoritative.

- `CLAUDE.md` defines the orchestrator and secure-development requirements.
- `agents/` contains focused review, test, planning, and remediation roles.

Agent output is advisory until verified by the governed repository gates.
Retired VibeCheck state under `DOCS/archive/` is never current authority.
