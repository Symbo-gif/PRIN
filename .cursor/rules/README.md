# .cursor/rules/ — Cursor project rules

Repository-tracked rules in this directory enforce PRIN source authority and
secure development in Cursor-compatible sessions. The active rule requires the
session brief, plan, standards, latest state/deviation evidence, governing audit,
and the Coding Standards §6 security gates before changes are claimed complete.

Retired VibeCheck rules are historical under `DOCS/archive/` and are not used as
current project truth.
