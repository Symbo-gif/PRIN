# prin-metrics

Synchronization metrics for PRIN: Kuramoto order parameter, mean phase
coherence, phase coherence matrix, PSD, sparse k-NN variants, and the full
chimera metric set (local order parameter, bimodality index, chimera index,
strength of incoherence, discontinuity measure).

Rebuild target for PRINet 3.0 `core/measurement.py` (full + sparse variants).
