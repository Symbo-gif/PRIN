### 2.1 `tests/_basetemp.py`

#### 1. Abspath Semantics
[`tests/_basetemp.py:86`](file:///C:/dev/PRIN/tests/_basetemp.py#L86) executes:
```python
target = Path(os.path.abspath(basetemp))
```
Pytest's `TempPathFactory.getbasetemp()` resolves relative paths via `os.path.abspath(str(basetemp))` against the process current working directory (the invocation directory). By computing `os.path.abspath(basetemp)`, `clear_stale_basetemp` resolves the identical filesystem path that pytest's factory would otherwise delete lazily.

#### 2. Root and Ancestor Protection
[`tests/_basetemp.py:87-90`](file:///C:/dev/PRIN/tests/_basetemp.py#L87-L90):
```python
root = rootdir.resolve()
resolved = target.resolve()
if resolved == root or resolved in root.parents:
    raise ValueError(f"refusing to delete {target}: it contains {root}")
```
- If `target` is the repository root (`resolved == root`), `ValueError` is raised immediately.
- If `target` is a parent or ancestor directory containing the repository (`resolved in root.parents`), `ValueError` is raised immediately.
- If `target` is an in-tree directory such as `.pytest_basetemp` (`resolved.parents` contains `root`), `resolved in root.parents` is `False`, allowing deletion of the intended directory.

#### 3. Bounded Deletion Loop
[`tests/_basetemp.py:91-106`](file:///C:/dev/PRIN/tests/_basetemp.py#L91-L106):
- The loop is bounded by `for _ in range(attempts):` (default `attempts=30`).
- If `remove(target)` succeeds, the subsequent loop iteration sees `not target.is_dir()` and breaks immediately without sleeping.
- If `remove(target)` encounters `PermissionError` (sharing violation, WinError 32), `failures` increments. If `failures >= attempts`, the error is raised; otherwise, `sleep(delay)` is called.
- If `remove(target)` does not raise but the directory continuously reappears (e.g. recreated immediately by an external process), the loop terminates after `attempts` iterations and executes the `else:` block:

#### 5. Python 3.11 `onerror` Branch vs Python 3.12+ `onexc` Branch
[`tests/_basetemp.py:40-50`](file:///C:/dev/PRIN/tests/_basetemp.py#L40-L50):
```python
def remove_tree(path: Path) -> None:
    """``shutil.rmtree`` that also deletes read-only files."""
    if sys.version_info >= (3, 12):
        shutil.rmtree(path, onexc=_make_writable_and_retry)
    else:  # pragma: no cover - Python 3.11 hosts (``onexc`` is 3.12+)
        shutil.rmtree(
            path,
            onerror=lambda function, name, info: _make_writable_and_retry(
                function, name, info[1]
            ),
        )
```
- In Python 3.12+, `shutil.rmtree` deprecated `onerror` in favor of `onexc(func, path, exc)`.
- In Python 3.11, `shutil.rmtree` invokes `onerror(func, path, exc_info)` where `exc_info` is `sys.exc_info() = (type, value, traceback)`. `info[1]` extracts the exception instance `value`.
- Both branches pass `(function, path, exception_instance)` to [`_make_writable_and_retry`](file:///C:/dev/PRIN/tests/_basetemp.py#L30-L37):
  ```python
  def _make_writable_and_retry(
      function: Callable[..., Any], path: str, error: BaseException
  ) -> None:
      if not isinstance(error, PermissionError) or not os.path.lexists(path):
          raise error
      os.chmod(path, stat.S_IWRITE | stat.S_IREAD)
      function(path)
  ```
  If `error` is a `PermissionError` caused by a read-only bit (e.g. git object file), it clears the read-only attribute and retries `function(path)`. Any other exception re-raises immediately.
